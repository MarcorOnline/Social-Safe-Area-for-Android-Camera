# Social Safe Area 1.0.0

First stable release. Download **Social-Safe-Area.apk** below and open it on an
Android 8.0+ device. No compilation is required. `SHA256SUMS.txt` contains its
SHA-256 checksum.

- Reels, TikTok or combined composition guides over your existing camera app.
- Draggable quick button, saved opacity and manual vertical alignment.
- Optional automatic display when opening your selected camera app.
- English fallback plus Italian, French, Spanish and German interfaces.
- Offline camera profiles with proximity matching and calibration JSON export.
- Information page with creator Marco Rinaldi, Instagram contact, project source
  and GPLv3 attribution.
- Native Android UI without third-party runtime libraries, ads or network access.

The reference layout was verified on Samsung Galaxy S26 Ultra (SM-S948B),
Android 17 / API 37, Samsung Camera 17.0.00.43, at 1080 × 2340 with a portrait
9:16 video preview. Other devices and preview layouts may need vertical
adjustment; landscape geometry and automatic preview detection are not supported.

Grant **Display over other apps** to draw over the camera. For automatic camera
following, choose your camera and enable **Safe Area camera detection** in
Accessibility settings. See the README for setup and current limitations.

This non-debug APK uses the same distribution signing key as v0.3.0-beta and can
update that public release in place. Locally debug-signed builds use a different
key and must be uninstalled before installing the public APK, removing their
saved settings.

Community PRs should target `develop`, especially for common camera-app offsets.

GPL-3.0-only. Corresponding source is available in GitHub's source archives for
this tag and at https://github.com/MarcorOnline/SocialSafeArea/tree/v1.0.0.
