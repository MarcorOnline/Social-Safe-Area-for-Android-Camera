# Social Safe Area 1.2.0

- Three independent checkboxes replace the mask dropdown: **Reel**, **TikTok**
  and **Subtitles**. Enable any combination, including switching all masks off.
- A new translucent blue subtitle rectangle is centred on the screen, just
  above the lower TikTok band. It shares the opacity and vertical alignment
  settings of the other guides.
- Fresh installs enable Reel and TikTok, with Subtitles off. Updates preserve
  the previously selected platform; all new selections are saved.
- Update checks, project links and release documentation now point directly to
  the renamed repository, **MarcorOnline/SocialSafeArea**.
- Both READMEs open with the same cover image used in the Pistacchissimo article.
- Expanded creator credits and project background in the app and READMEs,
  with links to Pistacchissimo and its shop. Both cover image variants are included.

The APK is signed with the existing distribution key. It updates the previous
public release without removing saved settings. Android 8.0 or later is required.

Verification: release build and Android lint; real-device checks for all eight
mask combinations, checkbox persistence, legacy preferences, subtitle placement,
guide rotation and GitHub update responses.

The corresponding GPL-3.0-only source is available in this tag and in
[the source tree](https://github.com/MarcorOnline/SocialSafeArea/tree/v1.2.0).
The release includes the signed APK and `SHA256SUMS.txt`.
