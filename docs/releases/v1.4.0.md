# Social Safe Area 1.4.0

- New **Shared space** app icon: a lime safe-area frame with a turquoise second
  layer. The approved design is available as SVG and PNG; all five explored
  concepts are preserved in `docs/design/logo-concepts`.
- Matching English and Italian promotional images, with the original camera
  photograph and layout preserved. Notifications use a transparent monochrome
  version of the new mark.
- A third **Experimental features** accordion contains **Show the mask only in
  "Video" mode**, off by default, with an explanation before enabling it.
- On an exact supported profile, accessible Photo controls temporarily hide the
  guide while keeping the quick button. Video restores the saved manual ON/OFF
  choice. Unknown modes fall back to manual control after a brief grace period.
- Recognition responds to selected-camera accessibility events, coalescing bursts
  rather than taking screenshots or polling. No control text is stored or sent.
  Window contents are not retrieved while the experiment is off or unsupported.
- Initial portrait profile for Samsung Camera in Italian, English, French,
  Spanish and German. Compatibility requires the device, Android API, camera
  package and camera version listed in the community JSON to match exactly.
- Updated help and translations in all five interface languages, a clickable
  GitHub contribution link and a shortcut to Android accessibility settings,
  with a fallback where the dedicated settings page is unavailable.
- Community profiles now support optional mode-recognition rules. Documentation,
  build-time validation, a camera-control inspector and a real-device transition
  check explain how to contribute without changing Java code.

The feature remains experimental: camera updates, language and orientation can
affect recognition. Long-recording battery and performance measurements remain
outstanding.

The APK is signed with the existing distribution key and updates previous public
releases without removing saved settings. Android 8.0 or later is required.

Verification completed: debug and release builds; Android lint with no errors;
instrumentation on the reference Samsung covering the compact home screen,
exclusive accordions, all eight mask combinations, subtitle placement and resets,
experimental default-off, exact profiles, five language rules and preservation
of manual ON/OFF; guide alignment at 0°, 90°, 180° and 270°. Experimental mode
and accessibility remain off on the reference phone after verification.

The corresponding GPL-3.0-only source is available in this tag and in
[the source tree](https://github.com/MarcorOnline/SocialSafeArea/tree/v1.4.0).
The release includes the signed APK and `SHA256SUMS.txt`.
