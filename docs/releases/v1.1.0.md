# Social Safe Area 1.1.0

- Shorter Android name: **Safe Area**. The GitHub display title is **Social Safe
  Area — Camera overlay for Reels and TikTok**; the prepared Google Play title is
  **Safe Area: Reels & TikTok**.
- A lightweight weekly update check when opening the app, using the latest
  stable GitHub release directly. No separate file needs to be maintained on a
  website. A newer version appears as an inline link to its GitHub release,
  without popups, notifications or automatic downloads.
- Network errors, GitHub rate limits and blocked/non-JSON responses leave the app
  usable and do not trigger repeated checks. The last valid result is cached.
- Internet permission is now used for the update check. No device identifiers or
  calibration data are sent; the endpoint/CDN sees standard connection metadata.

Maintainers: see [update checks and release instructions](https://github.com/MarcorOnline/Social-Safe-Area-for-Android-Camera/blob/v1.1.0/docs/app-updates.md).
