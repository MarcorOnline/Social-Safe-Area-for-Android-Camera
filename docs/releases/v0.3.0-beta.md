# Social Safe Area 0.3.0 beta

Download **Social-Safe-Area.apk** below and open it on an Android 8.0+ device.
No compilation is required. `SHA256SUMS.txt` contains its SHA-256 checksum.

- Bottom information button: creator Marco Rinaldi (MarcorOnline), GitHub and GPLv3 attribution.
- English fallback plus Italian, French, Spanish and German interfaces.
- Offline device/Android/camera profiles, with proximity matching and safe fallback.
- Manual vertical adjustment always wins; Reset restores the suggested profile.
- Copy calibration JSON from the information page to contribute camera offsets.
- Native overlay and quick button, without third-party runtime libraries or network access.

Verified on Samsung Galaxy S26 Ultra (SM-S948B), Android 17 / API 37,
Samsung Camera 17.0.00.43, at 1080 × 2340 with a portrait 9:16 video preview.

Grant **Display over other apps** to draw over the camera. For automatic camera
following, choose your camera and enable **Safe Area camera detection** in
Accessibility settings. See the README for illustrated-button download and setup.

This is a signed, non-debug release. It cannot replace a locally debug-signed
developer build in place; migrating from one requires uninstalling the old
build, which removes its settings. Normal future releases will retain this
distribution key. No uninstall is required for fresh installations.

Profiles are suggestions; other devices and preview layouts may need adjustment.
Community PRs should target `develop`, especially for common camera-app offsets.

GPL-3.0-only. Corresponding source is available in GitHub's source archives for
this tag and at https://github.com/MarcorOnline/Social-Safe-Area-for-Android-Camera/tree/v0.3.0-beta.
