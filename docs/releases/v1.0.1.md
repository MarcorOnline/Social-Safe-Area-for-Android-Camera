# Social Safe Area 1.0.1

Download **Social-Safe-Area-1.0.1.apk** below and open it on an Android 8.0+
device. No compilation is required. `SHA256SUMS.txt` contains its SHA-256 checksum.

- Fixed the guide moving and shrinking when Android rotates the display. It
  now stays anchored to the physical panel in all four directions, preserving
  its scale and saved vertical alignment.
- Removed the beta label from the home screen in all five supported languages.
- Added the app's origin at Pistacchissimo, its blog article, the @pistacchissimo
  Instagram profile and the creator's personal profile to the information page.
- APK filenames now include the app version to make downloaded files easier
  to identify. The release build generates the matching checksum automatically.

The guide retains its existing composition layout; this update does not add a
separate layout for landscape video or automatic camera-preview detection.

Rotation, reference geometry, information-page links and automatic camera
following were checked on Samsung Galaxy S26 Ultra (SM-S948B), Android 17 /
API 37, at 1080 × 2340. Debug and release builds passed Android Lint.

This non-debug APK uses the existing distribution signing key and can update
the public 1.0.0 release in place. Debug builds use a different key.

GPL-3.0-only. Corresponding source is available in GitHub's source archives for
this tag and at https://github.com/MarcorOnline/Social-Safe-Area-for-Android-Camera/tree/v1.0.1.
